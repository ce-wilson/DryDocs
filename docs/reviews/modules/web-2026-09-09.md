## Why this slot ran, recorded because it is the first firing where two instructions could be read against each other

Every one of the ten slots now carries a complete report, so the firing prompt's closing
clause — *"if the sweep has no unreviewed slots left, do not invent work: say so and
stop"* — is live for the first time. It does not apply, and the reasoning belongs in the
report rather than in a terminal message that nobody keeps:

- **Section 2 rule 4 covers this case explicitly:** *"take the slot with no report, **or the
  oldest report**; break ties by slot number."* There is no slot without a report, so the
  rule selects the oldest — `web-2026-09-05`, four days older than the next.
- **The plan anticipates the return in as many words.** Its slot-9 note says web *"sits at
  the end of the first cycle deliberately, so the sweep covers unreviewed ground **before
  returning to it**."*
- **The prompt itself settles the precedence:** *"the plan is the source of truth; if it
  disagrees with this prompt, the plan wins."*

So a second pass is the designed behaviour of a standing rotation, not invented work. What
WOULD be invented work is re-deriving the first pass's findings, and section 4 has an
answer for that too — the second pass *"has something to move against"*. This report's job
is therefore movement: what the prior report found, what has happened to it since, and what
is true now that was not then.
