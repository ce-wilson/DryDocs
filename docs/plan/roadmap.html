DryDocs — module roadmap

Per-module build-out vs. the backlog, with size estimates for open ideas. Assessments from docs/restructure/roadmap.yaml (updated 2026-08-08); counts and open items read live from backlog/. A roadmap without target dates — stages and sizes are relative judgments, not commitments.

INTERNAL — idea summaries ride along (PUBLISH-BOUNDARY.md).

Stages:
mature
built out; changes are refinements
active
under active build-out
early
core exists; maturation ahead
steady
steady-state; grows additively
parked
deliberately paused on a named trigger

Idea sizes:
S
one focused session
M
a few sessions, one backlog item
L
an epic slice — multiple sessions, usually a HITL gate
XL
a multi-epic program
